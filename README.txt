TYLER'S JACKLETE PWA

FILES
- index.html: workout tracker
- manifest.webmanifest: install metadata
- sw.js: offline cache
- icon-192.png and icon-512.png: app icons

DEPLOYMENT
A PWA must be hosted from a secure web origin for its service worker and installation features to work. Upload every file in this folder together, preserving the filenames.

GITHUB PAGES
1. Create a new GitHub repository.
2. Upload all five files to the repository root.
3. Open repository Settings, then Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and root folder, then save.
6. Open the published site on your phone.
7. iPhone: Safari > Share > Add to Home Screen. Android: Chrome menu > Install app or Add to Home screen.

DATA
Workout data is stored locally on each device. Use Export Data and Import Data inside the app to move or back up logs.
